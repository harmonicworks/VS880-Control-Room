Connections & VS-880 setup

VS-880: SYSTEM → MIDI PRM → MIDIThr=Out · SysEx.Rx=On · SysEx.Tx=On · CtrType=Excl · P.C.Eff=On · DeviceID 17. nanoKONTROL2 LEDs only light from the computer when its LED Mode is set to External (Korg Kontrol Editor).
